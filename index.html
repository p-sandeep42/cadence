CadenceYour day, in rhythm

Your data stays here

Everything you log is saved in this browser on this device. Nothing is sent anywhere. To move to another device, use Settings → Back up and import the file there.

Install it

  • Laptop: open cadence.html in Edge or Chrome and bookmark it. Always open the same file in the same browser.
  • Android: host the dist folder (for example on GitHub Pages), open it in Chrome and choose Install app. It works offline after that.
